---
name: resume
description: Pick up this repository's work where the last session left off, in any tool
---

Call `resume_work` on the Seturos MCP server, passing `repo` set to this repository's remote — read it
with `git remote get-url origin` and pass it as given; Seturos normalises it to `host/owner/name`.

What comes back is the work recorded in THIS repository, from every tool the person uses — Claude Code,
Codex, Cursor — plus the project it is linked to, if any. Sessions from other repositories are never
included, even when two repositories are linked to the same project.

Read it before re-deriving anything: it is what was actually decided and done, not a guess. Then tell
the person, in a sentence or two, where things stand and what the open threads are, and pick up from
there rather than restarting.

If Seturos offers to link this repository to a project, put the offer to the person in your own words
and wait — it changes where future sessions here are filed, and it is theirs to decide.
